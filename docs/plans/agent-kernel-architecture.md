# Agent Kernel Architecture

NyxHive is moving from a multi-agent-routing-first architecture to a persistent agent workspace architecture.

## Keep in Shell

- daemon
- channels
- scheduler
- notifications
- approvals/proposals
- memory databases
- run history/traces
- workspace UI

## Move Behind Kernel Seam

- session execution
- provider runtime invocation
- context assembly
- memory injection
- skill/package discovery
- tool registry
- normalized event stream

## Demote to Optional Capability

- automatic routing
- delegation engine
- dynamic agent registry
- learned routing
- teams
